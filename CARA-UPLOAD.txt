SNYP University x Kantor Skripsi: files to upload to GitHub (CHTLNXXY/SNYPSKRPS)

1. Unzip this file.
2. On GitHub open the repo, then Add file > Upload files.
3. Drag the folders public, lib, api, test plus dev-server.js into the upload box.
   GitHub keeps the folder paths and overwrites the files with the same name.
   Files that are not in this zip stay as they are.
4. Commit. Vercel redeploys automatically in about 1 minute.
